# SEC-110 Class Notes

Weekly class notes for SEC-110 (sections 01/02/03), published to this repo's [wiki](https://github.com/RustedOne/SEC-110-01-02-03/wiki).

The wiki pages live in the [`wiki/`](wiki/) folder, with images in `wiki/images/week-N/`. On every push to `main`, the [Publish wiki](.github/workflows/publish-wiki.yml) Action copies that folder into the GitHub wiki. Pages made directly in the wiki editor are left alone.

To delete a wiki page, add its file name (for example `Old-Page.md`) as a line in `wiki/.remove`.
